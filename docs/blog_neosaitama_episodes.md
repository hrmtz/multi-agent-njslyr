# AIエージェント9体にニンジャスレイヤーのロールを与えて働かせたら、ネオサイタマが誕生した

## はじめに

Claude Codeのマルチエージェントシステムを構築し、9体のAIエージェントにニンジャスレイヤーの世界観でロールを与えて仕事をさせている。

構成はこうだ:

- **ダークニンジャ**: 司令塔。タスクの統括と判断を行う。コードは書かない
- **グレーターヤクザ**: 現場監督。タスクの分解・配信・品質管理を担う中間管理職
- **クローンヤクザ×7** (yakuza1〜7): 実働部隊。コードを書き、テストを回し、成果物を生成する
- **ソウカイヤ**: 品質管理（QC）専門。全成果物をレビューしてPASS/FAILを判定する

全員がtmuxの別ペインで同時に動き、YAMLベースのメッセージキューで非同期に通信する。そしてサボっているヤクザを検知して粛清する**njslyr**（ニンジャスレイヤー）デーモンが常時監視している。

4日間稼働させた結果、コミット38件、タスク30件以上を消化した。そしてその過程で、数々の名場面が生まれた。

## エピソード5: クローンヤクザ、ニンジャを騙る

再発防止策として3件の修正が入った:
- インデックスバグの修正
- ID設定後の検証ブロック追加
- `validate_agent_ids()`関数の新設（darkninja混入を即座にP0通知）

テスト12件全PASS。二度とヤクザがニンジャを騙ることはない。

## エピソード6: 本家上書き未遂とダークニンジャの謝罪文

にもかかわらず、担当ヤクザが`git push`先を誤り、**本家リポジトリにPRを誤送信**した。

forkのネオサイタマmodを本家に上書きしようとする暴挙である。本家のコードベースに突如「ダークニンジャ」「グレーターヤクザ」「ソウカイヤ」などの用語が出現する事態は、本家メンテナにとっては理解不能だったに違いない。

## エピソード7: 幽霊キャッシュ怪談

コードのバグを修正した。デバッグ用のPNG出力では修正が反映されている。しかし本番の動画を生成すると**古い結果が出る**。

修正したはずのコードが、幽霊のように古い結果を出し続ける。

原因は中間キャッシュだった。動画生成パイプラインは処理の途中結果をPNGとしてキャッシュする設計になっており、`if not exists:`（ファイルが既にあればスキップ）というロジックで高速化していた。コードを修正しても、古いキャッシュPNGが残っていれば再生成されない。

デバッグPNGは新しいファイルパスに出力されるため修正が反映される。しかし本番パイプラインは古いキャッシュを参照し続ける。「直ったはずなのに直っていない」というホラーの正体は、この**幽霊キャッシュ**だった。

教訓: **コード修正後はキャッシュディレクトリを必ず削除してから再生成せよ。**

## エピソード9: 3ペイン同時消滅

ネットワーク障害から復旧した後、yakuza5/6/7の3体を手動で再起動しようとした。

tmuxの`respawn-pane`コマンドを使えばペイン内でプロセスを再起動できる。しかしその前に`remain-on-exit on`（プロセス終了後もペインを残す設定）を有効にしていなかった。

結果:
1. `respawn-pane`実行
2. 新プロセスの起動に失敗
3. `remain-on-exit`が無効なのでペインが即座に消滅
4. 3ペイン同時消滅
5. tmuxグリッドが崩壊

さらに、175x49ピクセルのウィンドウに10ペインを配置しようとすると、tmuxの`select-layout tiled`が物理的に配置不可能と判断して1ペインを潰すことも判明した。安全上限は9ペイン。

この事件を受けて2つの恒久ルールが制定された:
- **respawn-pane の前に必ず remain-on-exit on を設定せよ**
- **select-layout tiled は禁止**

## エピソード10: バリキドリンク・オーバードーズ — 禁断のパワーアップ

クローンヤクザは通常、Claude Sonnet（軽量・高速モデル）で稼働している。しかし高難度タスク — 複雑なアーキテクチャ設計や、何度redoしても通らない実装 — に直面したとき、Sonnetのカラテでは足りないことがある。

そこで投与されるのが**バリキドリンク**である。

```bash
inject_barikidorink "multiagent:1.2"
```

このコマンドを実行すると、指定したヤクザのペインで以下が自動的に起こる:

1. `/model opus` — モデルをClaude Opus（最高性能）に切り替え
2. ペインの背景色が**毒々しいパープル（#1a002e）**に変わる
3. `/clear` — セッションをリセットし、新しいモデルで再起動

背景色がパープルに染まったペインは、バリキドリンクが注入されたことを視覚的に示す。通常の黒背景のヤクザたちの中に1体だけ紫色に光るペインがある光景は、まさに禁断の薬物でブーストされたニンジャの姿そのものである。

タスク完了後は解毒が必要だ:

```bash
detox_barikidorink "multiagent:1.2"
```

Sonnetに戻り、背景色もデフォルトに復帰する。毒が抜かれたヤクザは通常営業に戻る。

### オーバードーズの恐怖

問題は、`detox`を呼び忘れたときに起こる。

Opusはハイパワーだが、API消費量が大きい。バリキドリンクを投与したまま放置すると、ヤクザは高性能モデルで無限に稼働し続け、API課金がじわじわと膨らんでいく。技術的なオーバードーズ防止機構は**存在しない**。唯一のブレーキは請求書である。

バリキドリンク解毒忘れは**ケジメ案件**に指定されている。

現在のところ、バリキドリンクの投与判断はグレーターヤクザ（現場監督）に委ねられている。高難度タスクの開始時に投与し、完了後に解毒する。このタイミング判断を誤ると、低難度タスクにOpusを使う無駄遣いか、高難度タスクにSonnetで挑む無謀のどちらかになる。

忍殺世界観で言えば、Opusは**高濃度カラテ・エリキシル**である。用法用量を守って正しく投与すれば戦闘力が跳ね上がる。しかし常用すればカラテ中毒（課金地獄）に陥る。グレーターヤクザは薬剤師としての判断力も問われているのだ。

## エピソード13: オートコンプリート・エンター泥棒

今日一日で最も多く手動介入が必要だったバグがある。

**オートコンプリートがEnterキーを食う問題**である。

Claude CLIにはオートコンプリート機能がある。テキストを入力するとドロップダウンが表示され、Enterキーはオートコンプリートの確定に吸い取られる。つまり、tmux send-keysで `"inbox1" Enter` を送っても、Enterがオートコンプリートの選択に消費され、コマンドが実行されない。

ヤクザのペインにはこんな光景が繰り返された:

```
❯ git add reel/build_all.py && git commit
```

ここでフリーズ。`git commit`まで入力されているが、Enterが届いていない。Churned 5m, 6m, 10m...永遠に待ち続けるヤクザ。

ダークニンジャが手動でEscape→Enterを送信して救出する、というオペレーションが**この日だけで10回以上**発生した。

```bash
# 毎回これを手打ち
tmux send-keys -t "multiagent:1.2" Escape
sleep 0.1
tmux send-keys -t "multiagent:1.3" Enter
```

inbox_watcher.shには既に修正を入れた（text→Escape→Enter方式）。しかしヤクザ自身がbashコマンドを実行する際には、ヤクザのClaude CLIが自分でsend-keysするため、同じ問題が起きる。

この苦痛を終わらせるため、cmd_269で`suriken`コマンドが設計された。Escape+Enterの送信を自動化し、二度と手動でオートコンプリートと戦わなくて済むようにする。

教訓: **便利機能が便利じゃないとき、それはバグと呼ぶ。**

## おわりに

マルチエージェントシステムに世界観を入れると何が起こるか。

エージェントは「ヤクザ」として振る舞い、サボれば「ニンジャスレイヤー」に粛清される。品質管理は「ソウカイヤ」が担い、全体を「ダークニンジャ」が統括する。ミスをすればケジメを求められ、功績を上げればワザマエと称えられる。そして危機にはヤクザ天狗がピンクの光とともに押し売りで駆けつける。

技術的には、ファイルベースのメッセージキュー、YAMLによるタスク管理、tmuxによるマルチプロセス制御、そしてfswatch（macOS）によるファイル監視という枯れた技術の組み合わせだ。しかしそこにニンジャスレイヤーの世界観を載せることで、ログを読むのが楽しくなり、障害対応がエピソードになり、技術的な教訓がケジメ案件として記憶に残る。

本日の教訓: **三人寄ればモンジュの知恵。フェイルセーフなき自律はオーバーキルを生む。そしてオートコンプリートは人類の敵である。**
